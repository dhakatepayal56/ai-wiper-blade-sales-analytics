# ai-wiper-blade-sales-analytics
This project analyzes wiper blade sales data to identify sales trends, top-performing products, customer purchasing patterns, and business growth opportunities using Data Analytics and Generative AI.

Technologies Used

Python (Pandas, NumPy, Matplotlib)

SQL

Microsoft Excel

Power BI and DAX

Generative AI

Project Objectives

Analyze total revenue, orders, and units sold.

Identify top-selling wiper blades and vehicle segments.

Track monthly and quarterly sales trends.

Analyze regional sales and customer behavior.

Generate AI-powered business insights and recommendations.
